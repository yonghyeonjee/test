## 6. 관리자 통계 탐색기(#296)

- 자료: 유입(사람 수) · 검색(조건 조회)
- 기간: 오늘 · 7일 · 30일 · 90일 · 올해 · 전체 · 직접(날짜)
- 단위: 시간 · 일 · 주 · 월 · 년(기간에 맞춰 자동, 바꿀 수 있음. 시간은 31일까지)
- 나누기: 유입 = 채널 · 사이트(리퍼러) · 도착 화면 갈래 · 도착 화면 · 검색어 · 캠페인 / 검색 = 조회 방식 · 갈래 · 지역 · 나이대 · 취업상태 · 결과 0건
- 집계: `sql/019_admin_stat_series.sql` 의 `admin_stat_series`(service_role 만). API `web/app/admin/stats/route.ts`(관리자 쿠키, 없으면 401). 화면 `web/app/admin/StatsExplorer.tsx`, 이름표 `web/lib/adminStats.ts`.
