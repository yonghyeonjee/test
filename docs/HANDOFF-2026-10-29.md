## 8. 지킬 것

- 비밀값은 GitHub Secrets·서버 .env 에만. NEXT_PUBLIC_ 에 넣지 않는다. 커밋·PR·로그에 값을 남기지 않는다. 사용자가 채팅에 값을 붙이지 않게 한다.
- 운영 서버 SSH 읽기(Production Reads)는 자동 모드에서 막힘 — 우회하지 않는다.
- Supabase 에서 DROP·대량 UPDATE 하지 않는다. robots.txt 를 지키고 봇 차단을 우회하지 않는다. 애드센스를 숨기거나 자르지 않는다.
- 커밋: `git -c user.name="yonghyeonjee" -c user.email="yonghyeonjee@gmail.com"`, 꼬리말 Co-Authored-By·Claude-Session. 커밋·PR 에 모델 이름을 쓰지 않는다.
