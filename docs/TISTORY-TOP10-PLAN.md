# 티스토리 순위 TOP10 연재 — 30일 기획 (2026-10-18 ~ 2026-11-16)

매일 **13:00 KST** 한 편. `.github/workflows/tistory_top10_daily.yml` 이 `pipeline/top10_plan.json` 에서 그날 주제를 꺼내
① `top10.py` 로 jiwon(blog_posts)에 순위 글을 쓰고(출처) ② `chart_top10.py` 로 차트 12장 + 접수 중 공고 화면 1장을 만들고
③ `tistory_publish.py --composer top10` 으로 티스토리용 글(출처 줄·참고 문헌·직무별 어려운 점)을 따로 써서 공개로 올린다.

- 숫자는 전부 jiwon DB 에서 센다. 글마다 "출처: K나라지원" 링크와 참고 문헌(원문·원 자료·심리 개념)이 붙는다.
- 직무·직렬 글은 항목마다 **어려운 점**을 심리학 개념(번아웃·감정노동·교대근무·역할 모호성·2차 외상 등)으로 풀고 jeepedia 자가진단으로 잇는다(`pipeline/top10_notes.py`).
- 사진은 화면 캡처가 아니라 자료 차트라 소제목마다 다르다.
- 카테고리는 글마다 자동: 채용·공무원·복지 → **policy**, 자격증(`license-*`) → **일상TIP**, 기업지원(`biz-field`) → **B2G**(`tistory_publish.category_for`).
- 주제 키는 `python pipeline/top10.py --list`. 날짜를 바꾸거나 주제를 끼워 넣으려면 `top10_plan.json` 만 고친다.
- 한 주제는 월 단위 slug(`top10-<주제>-YYYY-MM`)라 같은 달에 두 번 돌리면 덮어쓴다(티스토리는 `--update` 로 고쳐 쓴다).

## 글의 틀 (티스토리)

들머리(3~4줄) → 목차 → **현황은?**(요약 목록 + 차트 + 출처) → **1위 … 10위**(요약 목록 · 어떤 것인가 · *이 일이 힘든 이유*(직무·직렬) · 요즘 흐름 · 이렇게 준비하세요 · 출처)
→ **TOP10 비교**(표 + 차트) → **정리** → **참고 문헌**(jiwon 원문 · 원 자료 · 심리 개념 자가진단 · 번아웃 척도 논문).
