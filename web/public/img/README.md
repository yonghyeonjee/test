# 사진 넣는 곳

여기에 JPG 를 두면 화면이 자동으로 사진을 씁니다. 파일이 없으면 그림(SVG)이 대신 나옵니다.

| 파일 이름 | 쓰이는 곳 | 권장 크기 | 어울리는 사진 |
|---|---|---|---|
| `hero.jpg` | 첫 화면 오른쪽 | 1200×900 | 주민센터 창구, 서류를 보는 손, 동네 골목 아침 |
| `jobs.jpg` | 채용 화면 머리 | 1600×600 | 사무실, 면접 대기, 출근길 |
| `money.jpg` | 생활금융 머리 | 1600×600 | 아파트 단지, 열쇠, 통장 |
| `agency.jpg` | 공공기관 머리 | 1600×600 | 공공청사 외관, 도서관 열람실 |
